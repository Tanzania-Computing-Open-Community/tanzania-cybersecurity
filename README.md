# Tanzania Cybersecurity

A national open-source cybersecurity community repository for learning,
research, defensive security, responsible vulnerability research, labs,
CTFs, writeups, and security projects.

## Areas

- Learning
- Security roadmaps
- Web security
- Network security
- Authentication
- Cryptography
- Malware analysis
- Digital forensics
- Secure coding
- Cloud security
- Detection engineering
- CTFs
- Security research
- Vulnerability research
- Defensive security
- Threat intelligence
- Security tools
- Incident analysis

## Responsible Security

All cybersecurity activities must be performed legally and with appropriate
authorization.
